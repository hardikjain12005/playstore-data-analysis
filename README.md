# Google Play Store Data Analysis
### Mini Project — CSE 3rd Year

## Business Question
Where should a new developer launch 
their app on Google Play Store?

## Tools Used
- Python — Pandas, Matplotlib, Seaborn
- Power BI — Interactive Dashboard
- Excel — Data Exploration

## Dataset
- Source: Kaggle
- Total Apps: 10,841
- After Cleaning: 8,196 apps
- Categories: 33

## Key Findings
- 93% apps are free
- Photography is the best opportunity
- Free apps get 99x more downloads
- 78% apps have 4+ rating

## Project Structure
- data/ — Original and cleaned dataset
- notebooks/ — Jupyter notebook with full analysis
- visuals/ — All graphs and charts
- dashboard/ — Power BI dashboard file
- presentation/ — PPT file

## Final Recommendation
Launch a FREE Photography app targeting 
Everyone — best balance of demand 
and competition!
